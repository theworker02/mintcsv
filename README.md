# mintcsv

Mint structured JSON csv payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/mintcsv/

## Install / run

```bash
git clone https://github.com/theworker02/mintcsv.git
cd mintcsv
node src/cli.js
node --test
```
